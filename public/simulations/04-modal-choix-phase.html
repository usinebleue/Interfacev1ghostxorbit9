Clique sur un chantier pour choisir comment l'ouvrir: Analyser, Construire, ou Exécuter.

Parle à CarlOS...

Comment ça marche

1. Cliquez sur un chantier

Un popover apparaît avec 3 options: Analyser, Construire, Exécuter.

2. Choisissez votre mode

Chaque mode ouvre le chantier dans la phase correspondante.

3. Options grisées

Si la phase précédente n'est pas complétée, l'option est grisée avec un tooltip explicatif.

Dernière action

Aucune action encore
